# References and inspiration

- Apple ELEGNT: expressive and functional movement for a lamp-shaped robot. [Apple Machine Learning Research](https://machinelearning.apple.com/research/elegnt-expressive-functional-movement). Inspiration for using a simple body to communicate.
- Laban-inspired industrial-arm expressions: [RO-MAN demonstration page](https://brsrikrishna.github.io/ROMAN_25/). Reference for movement quality and real robot demonstrations.
- Human-created, understandable robot movements: [research paper](https://arxiv.org/html/2410.01071v1). Reference for human demonstration and readability studies.

The performances in this repository are independently choreographed. They do not reproduce Apple's source code, claim Apple affiliation, or implement sign-language translation. Sign language is a full language with lexical, grammatical and nonmanual components; an emotional word and the signer's emotional state are different things.
