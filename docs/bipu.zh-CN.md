# Bipu 本地系统

[English](bipu.md)

两条线都在原工程里：宠物模式根据消息和状态选动作；编排模式按固定脚本播放。八条确认轨迹保持原样。

## 现在怎么用

安装后运行 `bipu serve --open`，或直接双击本地 Bipu 文件夹里的“启动Bipu.command”。默认暂停，点击“开启宠物模式”即可发消息。停止按钮会取消后续动作和声音；“退出程序”、Ctrl+C 或关闭启动终端会结束服务。只关网页不会停止服务。

当前使用本地关键词规则，不需要密钥。输入“还不错”会开心；连续被凶会先受惊、再生气；安抚后逐渐缓和。没人发消息时，每隔 45–90 秒考虑一次活动，也可能保持安静；约四分钟后困倦，睡着后不反复演一遍睡觉。时间间隔和入睡时间可在配置里改。系统没有检测人在不在房间的能力，也不声称理解人的情绪。

动作正在播放时，消息排队，最多 16 条，超过 45 秒的旧消息不再执行。精力、心情和睡眠状态保存在本地；重启不自动开始。玩耍要求手动勾选“积木已摆在录制时的位置”，每次玩耍后自动取消勾选，需重新摆好再确认。说“给你玩具”不能代替现场确认，也没有堆叠成功识别。

## 预览和声音

本地已接好八段历史参考视频、27 条已选声音和 12 条备用声音。决策和队列真实运行，画面使用旧素材，不是实时摄像头。视频经过剪辑，时长不等于机械臂轨迹时长。

首次点一次“启用声音”。浏览器播音需要控制页保持前台；若希望在后台由电脑播音，可用 `serve --audio system`。声音按情绪分组，同组中变化选择，也允许安静。尽量不连续重复上一条。H05/H11/H20/H24 保持标心；J 组备用声音可手动选，不默认混进宠物声音池。

公开安装包仅含声音索引，不包含私有音频和参考视频。没有音频时仍能静音运行。其他使用者可以在配置里指定自己的 `sound_root` 和 `sound_manifest`，格式见英文文档。每条声音可指定所属情绪、是否作为默认候选；校验和用于避免误放同名旧文件。

## 编排模式

先停止宠物模式，再播放右侧脚本。可以选择动作和声音添加一段，也可以导入、导出 JSON。播放前会检查整份脚本：动作必须属于八条确认库，时间合法，声音属于对应情绪或标志/备用组，不重叠、不超出动作结束。每份脚本最多包含一次玩具动作，再次玩需要重新摆积木。

`wait_before` 是进入下一段前的等待秒数；声音的 `at` 从该段开始回放算起。实机对齐起始姿态另占时间。原动作时序不变。现有遥操、裁切和录制工具继续保留，这个页面负责调用确认片段。

## Jev 和 Telegram

2026-10-09：用户已在本机配置 Jev key，真实 API 联调已通过，本机默认切换为 Jev。Telegram 仍待凭据与真实服务测试。

运行 `bipu --config config.local.json configure` 可在本机隐藏输入密钥；再用 `serve --provider jev` 启动。Jev 只能选择本地允许的动作和声音，不能输出舵机角度。消息含义的判断置信度低、调用失败或格式错误时等待并显示原因。几条叫声都适合时，按模型返回的概率在允许的表现中抽样，不把叫声偏好的不确定性当成听不懂。判断会带上最近互动。API 文档和请求格式见英文文档。

Telegram 需填写 bot token、允许的私人聊天 ID，并显式设置 `telegram_enabled:true`。只接收白名单私聊的新文本，忽略启动前积压内容。`/stop` 可停止，不发送聊天回复。要先在本地开启宠物模式，远程消息不能打开硬件或确认道具。

## 实机边界

本次启动默认预览，不连接机械臂，不改变校准。已有控制器适配器，需显式提供 `--controller-runtime`，连接正在保持位置的原控制程序；已审查的动作衔接写入 `approved_transitions`。所有轨迹目标仍须通过原控制器限位。配置中的 START 指人工确认的当前姿态，不是通用原点；停止后再次开始前应重新确定姿态。

这一轮已做离线协议测试，没有进行实机连续动作衔接测试。停止请求保持力矩，不等于卸力。当前不能声称“插上机械臂即可无人看管运行”。后续实机验收只需接着这套系统做，不再重建。

## 本地资料

- `06_宠物系统/本地配置/config.json`：本机路径、模式和时间参数。
- 同目录 `runtime/`：运行状态、私有消息日志和当前会话文件。
- `03_开源代码/expressive-arm/src/expressive_arm/bipu/`：可公开审查的系统代码。
- `docs/bipu.md`：英文完整配置、接口与测试说明。

不要把整个 Bipu 文件夹上传 GitHub。音频、拍摄素材、聊天记录、密钥和设备校准不随本次代码变更发布。
