# Changelog

## 0.2.0 — 2026-10-07

- English and Chinese READMEs with use cases, compatibility status, installation and direct demonstration links.
- CSV export for timestamped joint targets, plus an offline Python integration example.
- Porting guidance for other SO-101 calibrations, SO-100 and other arm models; no new hardware support claimed.
- Contribution guide, issue forms, citation metadata, media license clarification and versioned release packages with checksums.
- Wheel/source distribution checks in CI; source packages include hardware tools and guides.
- Removed private session selection notes and narrative descriptions from public metadata. The eight trajectory files and their checksums are unchanged.

## 0.1.0 — 2026-10-07

- Initial release: eight SO-101 motion trajectories with checksums and linked demonstrations.
- Offline list, inspect, validate, SVG plot and crop commands.
- Separate leader/follower recording and replay tools; offline tests and CI.
